# Project Information

## Technologies Used

* **AI:** ChatGPT Pro
* **Map Service:** Google Cloud / Google Maps Platform
* **Application Images:** Stored in the `image` folder

## API Key Security

I removed the API key from the source code in `app.config.js`.

ChatGPT recommended not including API keys directly in a public GitHub repository because API keys are sensitive information. If an API key is publicly exposed, other people may be able to copy and use it without permission.

This could cause several problems, including:

* Unauthorized use of the API
* Unexpected API usage or quota consumption
* Additional charges or billing costs
* Abuse of the Google Cloud services connected to the API key
* Security risks to the project

For security reasons, the actual API key is not included in this public repository.
